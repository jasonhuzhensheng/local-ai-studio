Deploy the Local AI Studio source package on this fresh machine. Migrate the existing source; do not rebuild a similar website from scratch.
Language: English | 中文: INSTALL-PROMPT.txt

1. Read README-FIRST.en.txt and the source. Inspect OS, architecture, memory, free disk, GPU and installed tools. Report compatibility. Apple Silicon is the validated platform; identify adaptation work for other platforms instead of claiming direct support.
2. Use ~/Library/Application Support/LocalImageStudio: app for source, runtime for environments/engines/tasks, models for weights. Set app/.local -> ../runtime and runtime/image-models -> ../models. Avoid iCloud Desktop/Documents. Do not reuse old usernames, IPs or Tailnet identities.
3. Install required stable tools: Python 3.11, Node (the source machine used 25), CMake, build tools and LM Studio. Use isolated environments and install image/video dependencies separately from requirements/viggle-pinned.txt and src/h3_requirements.lock. If a version is unavailable or incompatible, report failure instead of silently upgrading. The H3/ClipProj Apple adaptation is experimental.
4. Deploy vendor/stable-diffusion.cpp and vendor/ggml-source into runtime. The source already includes changes; do not apply historical patches twice. Use the CMake configuration: -DSD_METAL=ON -DSD_WEBP=OFF -DSD_WEBM=OFF -DSD_GGML_SOURCE_DIR=<absolute ggml path> -DCMAKE_BUILD_TYPE=Release. Build sd-cli and other targets required by the code.
5. Download pinned revisions using the model JSON manifests and installers under src/. Support resume and verify sizes/SHA256. Obtain trusted upstream hashes where missing and record them; never invent hashes. Select runnable modules according to memory/disk capacity; do not silently substitute models. Install the README-specified text model in LM Studio with the alias used by the code, local API port 1234. Do not copy old account configuration.
6. Install video separately in video-experimental: ComfyUI from https://github.com/comfyanonymous/ComfyUI and ClipProj from https://github.com/nicolab28/ComfyUI-ClipProj. Pin the commits recorded under patches/ and apply each deployed.patch once. Download and verify h3_apple_models.json assets. Preserve memory protection. Do not also apply src/h3_apple_*.patch. Check the current code's supported resolution/frame/audio combinations; do not expand unvalidated capabilities.
7. Audit hardcoded /Users/ paths, environment variables, model directories and executables for the target machine. Preserve /edit, /chat, /video, task IDs/queues/progress, deletion confirmation, background chat tasks and references. Do not import old chats/tasks/reference images. Preserve the 中文 / English selector and language preference.
8. Start node app/src/image_gallery.mjs on loopback with the source-defined environment. Verify HTTP and model readiness. Avoid conflicts on ports 1235 (web), 1234 (text API), 8191 (video backend). Configure LAN/private Tailscale only if requested; do not enable public Funnel. Read the new device's address instead of reusing an old address.
9. Run relevant isolated tests. With newly written non-sensitive prompts, verify complete chat responses, stop/reconnect after refresh, real image output with visual inspection and playable short video. Record time/dimensions/memory. HTTP 200 or file existence alone is not acceptance.
10. Configure startup after local user login, display name Local AI Studio. If pre-login operation is requested, check OS/FileVault constraints first. A login LaunchAgent is not startup without login.
11. Save local deployment instructions, start/stop commands, paths/model/dependency versions and validation results. Do not read unrelated private files. Let the user enter administrator passwords or account logins; continue other authorized installation work. State remaining blockers and never claim unperformed checks passed.
12. Website authentication is enabled by default. Have the user create the first administrator at local /setup, then test authenticated business APIs. Unauthenticated /api/models returning 401 is expected. Do not disable authentication or copy an old account database. See docs/accounts.en.md.
