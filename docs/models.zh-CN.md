# 支持模型与范围

[English](models.en.md) · [简体中文](models.zh-CN.md) · [Docs](README.md) / [目录](README.zh-CN.md)

公开发布版图像选择器目前提供以下模型系列。菜单里出现模型不代表已安装权重，是否可运行取决于实际环境。

| 模型 / 组件 | 用途 | 说明 |
| --- | --- | --- |
| Qwen-Image-2.1 | 文生图与参考图编辑 | 核对权重、参考图数量和尺寸限制。 |
| WAI-Illustrious SDXL v17 | 插画文生图 | 不作为照片身份保持能力的证明。 |
| Viggle Turbo Qwen v0.1 | 四步图像流程 | 需要匹配的底模与适配器。 |
| Viggle v0.2.1 预览版 | 六步图像流程 | 属于预览版本，需单独安装验收。 |
| Viggle v0.3 | 六步与九步图像流程 | 步数更多不保证画质更好。 |
| Real-ESRGAN x4plus | 可选超分组件 | 导出尺寸不等于原生细节或高保真恢复。 |
| LM Studio 中的 Qwen3.8 27B | 文字对话 | 使用规定模型别名，权重另行安装。 |
| H3 FL2VA / Ref2VA | 实验视频 | 独立后端，受内存保护和支持参数组合限制。 |

固定版本请查看 `src/` 中对应 JSON 清单：`image_models.json`、`wai_model.json`、`viggle_turbo*_model.json`、`upscale_model.json`、`h3_apple_models.json`。另见 [Viggle 安装](viggle-v03.md)和[迁移说明](../README-先读我.txt)。

## 发布版与开发环境

开发机器可能有 Iris、其他 Turbo 变体、BFS/换装、上下文增强或更新的模型样张弹窗。本地做过测试不等于这些功能已包含在公开选择器中，使用前须核对当前源码和安装工具。本次文档更新不同步私有运行数据，也不新增这些模型。

## 怎样比较结果

记录完整提示词/负面提示词、输入图片、种子、尺寸、步数、采样器、模型版本、机器及耗时统计范围。原图与真实输出对照，并以一致比例检查细节。视频还需记录帧数、帧率、时长、音频和参考图数量。生成出文件与画质验收是两件事。

不同分辨率、模型加载状态和流程的耗时不能当作同条件性能排名。本仓库不承诺普遍生成速度，也不宣称完成了全新机器全流程安装验收。各模型及上游组件分别遵循其许可。
