# 故障排查

[English](troubleshooting.en.md) · [简体中文](troubleshooting.zh-CN.md) · [Docs](README.md) / [目录](README.zh-CN.md)

| 现象 | 优先检查 |
| --- | --- |
| 网页打不开 | 已配置网页服务是否运行、1235端口是否冲突、地址是否允许；查看脱敏后的本地服务日志。 |
| 接口返回401 | 先登录，这是正常鉴权行为，不要关闭鉴权来修复。 |
| 无法创建首个管理员 | 在服务所在Mac用127.0.0.1打开`/setup`；远程首次设置受限，不得覆盖已有账号库。 |
| 模型禁用或缺失 | 核对对应清单、下载完成情况、运行路径和依赖。列出模型不等于已安装。 |
| 文字失败或停滞 | 核对LM Studio的1234端口API与`qwen3.8-27b-local`别名；重启前检查活动任务。 |
| 视频不可用 | 核对独立后端、8191端口、支持参数和资源保护，不降低保护阈值。 |
| 输出模糊或改变原图 | 按原生尺寸查看结果，核对尺寸、提示词和增强设置；更大导出尺寸不证明细节恢复。 |
| 界面混合语言 | 首次跟随浏览器语言，可手动选择英文或中文；上游错误和系统弹窗可能保留原语言。 |
| 无法直接分享 | 浏览器/设备支持不同，使用下载与复制方式；查看本版[使用指南](usage.zh-CN.md)。 |

反馈时提供提交/版本、模型ID、Mac芯片/内存、macOS、尺寸/步数、复现操作及脱敏错误。移除个人图片、提示词、聊天、凭据和私有地址。不要无差别运行所有测试，部分会调用真实模型、下载文件或依赖运行服务。

不要用全环境静默升级替代缺失固定依赖的恢复，也不要终止用户任务或恢复旧快照来让检查通过。新机器只有在真实推理与输出检查后，才能记录该机器完成验收。
