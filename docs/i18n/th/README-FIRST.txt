เอกสารเหล่านี้เป็นการแปลข้อความโครงการสาธารณะด้วยคอมพิวเตอร์และยังไม่ได้รับการตรวจสอบโดยเจ้าของภาษาทั้งหมด ปรึกษาแหล่งข้อมูลภาษาอังกฤษหรือจีนสำหรับความคลุมเครือทางเทคนิค ไม่มีข้อมูลส่วนตัวของผู้ใช้รวมอยู่ด้วย

Local AI Studio: แพ็คเกจต้นทางการย้ายสำหรับ Apple Silicon Mac ใหม่

รุ่นที่ได้รับการตรวจสอบนี้ประกอบด้วยแหล่งที่มาของ frontend/backend การทดสอบ รายการดาวน์โหลดโมเดล การขึ้นต่อกันที่ปักหมุด แหล่งที่มาของกลไกดั้งเดิม และแพตช์วิดีโอ Apple รุ่นทดลอง อาจล้าหลังการพัฒนาหรือการผลิตในท้องถิ่น
ไม่รวมน้ำหนัก สภาพแวดล้อมเสมือนจริง งานก่อนหน้า รูปภาพอ้างอิง บันทึกการแชท การกำหนดค่าบัญชี และความลับ ไม่ใช่ app เพียงคลิกเดียว

มอบโฟลเดอร์ทั้งหมดนี้ให้กับผู้ช่วยเขียนโค้ดบน Mac เป้าหมายพร้อมกับ INSTALL-PROMPT.en.txt
เครื่องตรวจสอบเดิมคือ M2 Max พร้อมหน่วยความจำ 96GB ตรวจสอบรุ่นเป้าหมาย หน่วยความจำ และ OS ก่อน อย่าใช้การตั้งค่าวิดีโอซ้ำแบบสุ่มสี่สุ่มห้าบน Mac ที่มีหน่วยความจำต่ำกว่า

สารบัญ:
 ส่วนหน้า src/, แบ็กเอนด์, เครื่องมือ download/validation, รายการโมเดล
 การทดสอบ tests/; บางส่วนจำเป็นต้องติดตั้ง models/services. อย่ารันทั้งหมดโดยไม่เลือกปฏิบัติ
 requirements/viggle-pinned.txt สภาพแวดล้อมรูปภาพที่ปักหมุด
 src/h3_requirements.lock แยกสภาพแวดล้อมวิดีโอที่ปักหมุดไว้
 ต้นฉบับ vendor/ ที่ไม่มีไบนารีที่คอมไพล์ รักษาใบอนุญาตต้นน้ำ
 patches/ ComfyUI/ClipProj คอมมิตและปรับใช้การเปลี่ยนแปลง Python
 SHA256SUMS.txt เช็คซัมต่อไฟล์

จุดเริ่มต้นของโมเดล: image_models.json (Qwen GGUF), viggle_turbo_model.json / viggle_turbo_v021_model.json / viggle_turbo_v03_model.json (ฐาน model/adapters), wai_model.json, upscale_model.json และ h3_apple_models.json (วิดีโอ) ภายใต้ src/. ตรวจสอบแต่ละรายการและโปรแกรมติดตั้งก่อนที่จะดาวน์โหลด
โมเดลข้อความ: huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF, ไฟล์ Huihui-Qwen3.8-27B-abliterated-UD-Q4_K_XL.gguf แพ็คเกจนี้ไม่รวม revision/hash ที่ปักหมุดไว้อย่างสมบูรณ์สำหรับรุ่นนั้น รับและบันทึกข้อมูลเมตาอัพสตรีมที่เชื่อถือได้ก่อน อย่าอ้างสิทธิ์ความเท่าเทียมกันแบบไบต์ต่อไบต์กับเครื่องดั้งเดิม

การติดตั้งเครื่องใหม่ยังไม่ได้รับการตรวจสอบ ตรวจสอบเส้นทางเครื่องดั้งเดิม นามแฝงรุ่น และเส้นทางเครื่องมือระบบสำหรับผู้ใช้เป้าหมาย อย่าใช้แพตช์ที่ผ่านมากับแหล่งที่มาของผู้จำหน่ายที่แก้ไขแล้ว การดาวน์โหลดที่สำเร็จไม่ใช่หลักฐานของการอนุมานที่สำเร็จหรือคุณภาพที่ยอมรับได้

ใช้เมนูภาษาที่มุมขวาบนเพื่อเลือกภาษาของ 33 เบราว์เซอร์จะจดจำการเลือกของคุณ ชุดภาษามีให้บริการในพื้นที่ การเปลี่ยนภาษาไม่ได้ส่งเนื้อหาไปยังบริการแปลออนไลน์ ข้อความแจ้งของผู้ใช้ การสนทนา และเนื้อหาที่บันทึกไว้จะคงเป็นภาษาต้นฉบับ
