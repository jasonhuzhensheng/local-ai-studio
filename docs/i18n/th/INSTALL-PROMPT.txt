เอกสารเหล่านี้เป็นการแปลข้อความโครงการสาธารณะด้วยคอมพิวเตอร์และยังไม่ได้รับการตรวจสอบโดยเจ้าของภาษาทั้งหมด ปรึกษาแหล่งข้อมูลภาษาอังกฤษหรือจีนสำหรับความคลุมเครือทางเทคนิค ไม่มีข้อมูลส่วนตัวของผู้ใช้รวมอยู่ด้วย

ปรับใช้แพ็คเกจต้นทาง Local AI Studio บนเครื่องใหม่นี้ ย้ายแหล่งที่มาที่มีอยู่ อย่าสร้างเว็บไซต์ที่คล้ายกันขึ้นมาใหม่ตั้งแต่ต้น

1. อ่าน README-FIRST.en.txt และแหล่งที่มา ตรวจสอบระบบปฏิบัติการ สถาปัตยกรรม หน่วยความจำ ดิสก์ว่าง GPU และเครื่องมือที่ติดตั้ง รายงานความเข้ากันได้ Apple Silicon เป็นแพลตฟอร์มที่ได้รับการตรวจสอบแล้ว ระบุงานดัดแปลงสำหรับแพลตฟอร์มอื่นๆ แทนที่จะอ้างว่าได้รับการสนับสนุนโดยตรง
2. ใช้ ~/Library/Application Support/LocalImageStudio: app สำหรับแหล่งที่มา, runtime สำหรับ environments/engines/tasks, models สำหรับน้ำหนัก ตั้งค่า app/.local -> ../runtime และ runtime/image-models -> ../models. หลีกเลี่ยง iCloud Desktop/Documents. อย่าใช้ชื่อผู้ใช้, IP หรือข้อมูลประจำตัว Tailnet เก่าซ้ำ
3. ติดตั้งเครื่องมือที่เสถียรที่จำเป็น: Python 3.11, Node (เครื่องต้นทางที่ใช้ 25), CMake, เครื่องมือสร้างและ LM Studio ใช้สภาพแวดล้อมแบบแยกและติดตั้งการขึ้นต่อกันของ image/video แยกจาก requirements/viggle-pinned.txt และ src/h3_requirements.lock. หากเวอร์ชันไม่พร้อมใช้งานหรือเข้ากันไม่ได้ ให้รายงานความล้มเหลวแทนการอัพเกรดแบบเงียบๆ การปรับตัวของ Apple H3/ClipProj อยู่ในขั้นทดลอง
4. ปรับใช้ vendor/stable-diffusion.cpp และ vendor/ggml-source ใน runtime แหล่งที่มามีการเปลี่ยนแปลงอยู่แล้ว อย่าใช้แพตช์ประวัติศาสตร์สองครั้ง ใช้การกำหนดค่า CMake: -DSD_METAL=ON -DSD_WEBP=OFF -DSD_WEBM=OFF -DSD_GGML_SOURCE_DIR=<absolute ggml path> -DCMAKE_BUILD_TYPE=Release. Build sd-cli และเป้าหมายอื่น ๆ ที่จำเป็นสำหรับโค้ด
5. ดาวน์โหลดการแก้ไขที่ปักหมุดไว้โดยใช้รายการและตัวติดตั้งของโมเดล JSON ภายใต้ src/. สนับสนุนดำเนินการต่อและตรวจสอบ sizes/SHA256. รับแฮชอัพสตรีมที่เชื่อถือได้ในกรณีที่หายไปและบันทึกไว้ ไม่เคยคิดค้นแฮช เลือกโมดูลที่รันได้ตามความจุของ memory/disk อย่าเปลี่ยน models อย่างเงียบๆ ติดตั้งโมเดลข้อความที่ระบุ README ใน LM Studio ด้วยนามแฝงที่ใช้โดยโค้ด ซึ่งเป็นพอร์ต API ภายในเครื่อง 1234 อย่าคัดลอกการกำหนดค่าบัญชีเก่า
6. ติดตั้งวิดีโอแยกกันใน video-experimental: ComfyUI จาก https://github.com/comfyanonymous/ComfyUI และ ClipProj จาก https://github.com/nicolab28/ComfyUI-ClipProj. ปักหมุดคอมมิตที่บันทึกไว้ภายใต้ patches/ และใช้ deployed.patch แต่ละตัวหนึ่งครั้ง ดาวน์โหลดและตรวจสอบทรัพย์สิน h3_apple_models.json ปกป้องการป้องกันหน่วยความจำ อย่าใช้ src/h3_apple_*.patch ด้วย ตรวจสอบชุดค่าผสม resolution/frame/audio ที่รองรับของโค้ดปัจจุบัน อย่าขยายขีดความสามารถที่ไม่ได้รับการตรวจสอบ
7. ตรวจสอบพาธฮาร์ดโค้ด /Users/ ตัวแปรสภาพแวดล้อม ไดเร็กทอรีโมเดล และไฟล์ปฏิบัติการสำหรับเครื่องเป้าหมาย เก็บรักษา /แก้ไข, /แชท, /วิดีโอ, งาน IDs/queues/progress, การยืนยันการลบ, งานแชทในพื้นหลัง และการอ้างอิง ห้ามนำเข้าอิมเมจ chats/tasks/reference เก่า คงตัวเลือกภาษาจีน / ภาษาอังกฤษและการตั้งค่าภาษาไว้
8. เริ่ม node app/src/image_gallery.mjs บนลูปแบ็คด้วยสภาพแวดล้อมที่กำหนดโดยแหล่งที่มา ตรวจสอบความพร้อมของ HTTP และโมเดล หลีกเลี่ยงความขัดแย้งบนพอร์ต 1235 (เว็บ), 1234 (API ข้อความ), 8191 (แบ็กเอนด์วิดีโอ) กำหนดค่า LAN/private Tailscale เฉพาะเมื่อมีการร้องขอเท่านั้น อย่าเปิดใช้งาน Funnel สาธารณะ อ่านที่อยู่ของอุปกรณ์ใหม่แทนที่จะใช้ที่อยู่เก่าซ้ำ
9. เรียกใช้การทดสอบแยกที่เกี่ยวข้อง ด้วยข้อความแจ้งที่ไม่ละเอียดอ่อนที่เขียนขึ้นใหม่ ตรวจสอบการตอบกลับแชทที่สมบูรณ์ stop/reconnect หลังจากการรีเฟรช เอาท์พุตภาพจริงพร้อมการตรวจสอบด้วยภาพและวิดีโอสั้นที่สามารถเล่นได้ บันทึก time/dimensions/memory. HTTP 200 หรือการมีอยู่ของไฟล์เพียงอย่างเดียวไม่เป็นที่ยอมรับ
10. กำหนดค่าการเริ่มต้นหลังจากการเข้าสู่ระบบของผู้ใช้ภายใน ชื่อที่แสดง Local AI Studio หากมีการร้องขอการดำเนินการเข้าสู่ระบบล่วงหน้า ให้ตรวจสอบข้อจำกัดของ OS/FileVault ก่อน การเข้าสู่ระบบ LaunchAgent ไม่เริ่มต้นโดยไม่มีการเข้าสู่ระบบ
11. บันทึกคำแนะนำการปรับใช้เฉพาะเครื่อง คำสั่ง start/stop เวอร์ชัน paths/model/dependency และผลการตรวจสอบ อย่าอ่านไฟล์ส่วนตัวที่ไม่เกี่ยวข้อง ให้ผู้ใช้ป้อนรหัสผ่านผู้ดูแลระบบหรือการเข้าสู่ระบบบัญชี ดำเนินการติดตั้งอื่นๆ ที่ได้รับอนุญาตต่อไป ระบุตัวบล็อกที่เหลืออยู่และอย่าเรียกร้องการตรวจสอบที่ไม่ได้รับการดำเนินการ
12. การรับรองความถูกต้องของเว็บไซต์ถูกเปิดใช้งานตามค่าเริ่มต้น ให้ผู้ใช้สร้างผู้ดูแลระบบคนแรกที่ /setup ภายในเครื่อง จากนั้นทดสอบ API ธุรกิจที่ผ่านการรับรองความถูกต้อง คาดว่าจะไม่ได้รับการรับรองความถูกต้อง /api/models ที่ส่งคืน 401 อย่าปิดใช้งานการรับรองความถูกต้องหรือคัดลอกฐานข้อมูลบัญชีเก่า ดู docs/accounts.en.md.
