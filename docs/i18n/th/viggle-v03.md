> เอกสารเหล่านี้เป็นการแปลข้อความโครงการสาธารณะด้วยคอมพิวเตอร์และยังไม่ได้รับการตรวจสอบโดยเจ้าของภาษาทั้งหมด ปรึกษาแหล่งข้อมูลภาษาอังกฤษหรือจีนสำหรับความคลุมเครือทางเทคนิค ไม่มีข้อมูลส่วนตัวของผู้ใช้รวมอยู่ด้วย

# การติดตั้งและโหมด Viggle v0.3

แหล่งที่มาอย่างเป็นทางการ: https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo

การแก้ไข ขนาด และแฮชที่ปักหมุด: `src/viggle_turbo_v03_model.json` โปรแกรมติดตั้ง: `src/install_viggle_turbo_v03.py` ใช้ไดเร็กทอรี `models/viggle-qwen-turbo-v03` แยกต่างหากในขณะที่แชร์โมเดลพื้นฐานที่ติดตั้งและสภาพแวดล้อม Python ที่มีอยู่ มันไม่ได้อัพเกรดการพึ่งพาหรือเขียนทับ v0.1/v0.2.1.

เมนูโมเดลรูปภาพนำเสนอ:

- **Viggle v0.3 · ขั้นตอน 6, ภาพที่สะอาดตา**: กำหนดการซิกม่าหก node อย่างเป็นทางการ, CFG1
- **Viggle v0.3 · ขั้นตอน 9, รายละเอียดที่ได้รับการปรับปรุง**: ขั้นตอน Turbo เจ็ดขั้นตอน จากนั้นปิดใช้งาน LoRA สลับการส่งผ่าน KV ที่แคชไว้ครั้งถัดไปเป็นการแยก และใช้โมเดลพื้นฐานสำหรับสองขั้นตอนสุดท้าย LoRA และพฤติกรรมการส่งต่อจะได้รับการกู้คืนในภายหลัง การตั้งค่าการนับก้าวปกติเป็นเก้าก้าวไม่เท่ากัน

v0.3 รองรับการอ้างอิงสูงสุดสามรายการ ไม่มีพรอมต์เชิงลบ และค่าเริ่มต้นสี่เหลี่ยมจัตุรัส 1024px เมื่อเลือก ขนาดเริ่มต้นและขนาด iPhone ของ v0.2.1 ก่อนหน้าจะยังคงอยู่ รุ่นดั้งเดิมยังคงรองรับการอ้างอิงสิบรายการ ขนาดใหญ่ดั้งเดิม การปูกระเบื้อง VAE และการประมวลผลหลังการประมวลผล 8K ที่มีอยู่ยังคงสามารถเลือกได้ แต่ไม่ใช่ทุกชุดที่ได้รับการทดสอบ

LoRA ไม่ได้รวมเข้ากับตุ้มน้ำหนัก BF16; ความแรงคือ 1 ตัวกำหนดเวลา `shift_terminal` ต้องเป็น null v0.3 อาจมีเม็ดหยาบน้อยลงแต่นุ่มนวลกว่าเล็กน้อย ไม่รับประกันว่าจะมีประสิทธิภาพเหนือกว่าเวอร์ชันเก่าในทุกกรณี อัตราส่วนเวลาเก้าขั้นตอนอย่างเป็นทางการไม่ใช่เกณฑ์มาตรฐานในท้องถิ่น

## การตรวจสอบ

`tests/viggle_model.mjs` ใช้ฟิกซ์เจอร์แบบจำลองกระจัดกระจายแบบแยกเดี่ยวเพื่อตรวจสอบจำนวนขั้นตอน ขีดจำกัดการอ้างอิง การกำหนดเส้นทางขนาดใหญ่ และเครื่องหมายความพร้อม `tests/viggle_schedule.py` ตรวจสอบการปิดใช้งาน LoRA หลังจากขั้นตอนที่เจ็ด โดยการแยกและกู้คืน KV อีกครั้งหนึ่งรายการ

512×512 หกขั้นตอน ตัวอย่างเมล็ด-42 ถ้วยสีน้ำเงินเสร็จสมบูรณ์ใน 52.98s รวมถึงการโหลด process/model ตรวจสอบขนาดและภาพจริงแล้ว ความพยายามเก้าขั้นตอนแรกหยุดลงเมื่อการเชื่อมต่อข้อความใหม่ทริกเกอร์การปกป้องทรัพยากร นี่ไม่ใช่ข้อผิดพลาดในการอนุมาน

การลองใหม่เก้าขั้นตอนเสร็จสมบูรณ์ใน 65.42 ที่ 512 × 512, เมล็ด 42 หลังจากขั้นตอนที่ 7 เปลี่ยนไปใช้โมเดลพื้นฐาน เสร็จสิ้น 9 ขั้นตอนและสร้างขนาดที่ถูกต้อง การตรวจสอบด้วยสายตาไม่พบเสียงรบกวนของ green/magenta หนึ่งตัวอย่างต่อโหมดไม่ใช่เกณฑ์มาตรฐานประสิทธิภาพที่มั่นคง การอ้างอิงหลายรายการ รูปภาพขนาดใหญ่ และการประมวลผลหลังการประมวลผล 8K ไม่ได้รับการตรวจสอบโดยการรันเหล่านั้น
