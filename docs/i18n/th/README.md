# MacBook Pro Studio

สตูดิโอภาพ แชท และวิดีโอทดลองในพื้นที่สำหรับ Apple Silicon Mac

## ภาษาอินเทอร์เฟซ

ใช้เมนูภาษาที่มุมขวาบนเพื่อเลือกภาษาของ 33 เบราว์เซอร์จะจดจำการเลือกของคุณ ชุดภาษามีให้บริการในพื้นที่ การเปลี่ยนภาษาไม่ได้ส่งเนื้อหาไปยังบริการแปลออนไลน์ ข้อความแจ้งของผู้ใช้ การสนทนา และเนื้อหาที่บันทึกไว้จะคงเป็นภาษาต้นฉบับ

## ตัวอย่างอินเทอร์เฟซ

การแสดงตัวอย่างเหล่านี้ใช้สไตล์เพจที่เผยแพร่ ข้อความแจ้ง รหัสงาน การประทับเวลา ภาพประกอบ และการสนทนาทั้งหมดเป็นเนื้อหาสาธิตที่สร้างขึ้นสำหรับ README นี้ ไม่มีบัญชีจริง รูปภาพของผู้ใช้ หรือบันทึกการแชท ภาพประกอบถูกวาดขึ้นโดยทางโปรแกรม ไม่ใช่แบบจำลองการวัดประสิทธิภาพหรือการกล่าวอ้างคุณภาพ

### สตูดิโอภาพ

เลือกรุ่น ป้อนข้อความแจ้ง และเรียกดูงานและผลลัพธ์รูปภาพ

## ตั้งค่า Mac เครื่องใหม่

1. โคลนที่เก็บนี้
2. อ่าน [คู่มือการปรับใช้](README-FIRST.txt) ([中文](../../../README-先读我.txt))
3. มอบ [พร้อมท์การติดตั้ง](INSTALL-PROMPT.txt) ([中文](../../../INSTALL-PROMPT.txt)) ให้กับผู้ช่วยเขียนโค้ดบน Mac เป้าหมายเพื่อติดตั้งการขึ้นต่อกันและดาวน์โหลด models ที่เหมาะสมสำหรับฮาร์ดแวร์นั้น

หน้า: `/edit` สำหรับรูปภาพ, `/chat` สำหรับการแชท, `/video` สำหรับวิดีโอ เว็บพอร์ตเริ่มต้นคือ `1235`

พื้นที่เก็บข้อมูลนี้เป็นสำเนารุ่นที่ได้รับการตรวจสอบและการย้ายข้อมูล อาจล้าหลังการพัฒนาหรือการผลิตในท้องถิ่น โดยไม่รวมน้ำหนักโมเดล สภาพแวดล้อมเสมือนจริง งานของผู้ใช้ บันทึกการสนทนา รูปภาพอ้างอิง และการกำหนดค่าบัญชี การติดตั้งเสร็จสมบูรณ์บนเครื่องใหม่ยังไม่ได้รับการตรวจสอบ นี่ไม่ใช่แอปพลิเคชันแบบคลิกเดียว

## เนื้อหาที่เก็บข้อมูล

- `src/`: ส่วนหน้า แบ็กเอนด์ รายการโมเดล การติดตั้งและเครื่องมือตรวจสอบความถูกต้อง
- `tests/`: การทดสอบ; บางตัวจำเป็นต้องติดตั้ง models หรือเรียกใช้บริการ
- `requirements/`: การพึ่งพาที่ปักหมุดไว้
- `vendor/`: แหล่งที่มาของเอ็นจิ้นดั้งเดิมพร้อมลิขสิทธิ์อัปสตรีมยังคงอยู่
- `patches/`: เวอร์ชันที่ปักหมุดไว้และการดัดแปลงของ Apple

โมเดลและแหล่งที่มาจากบุคคลที่สามยังคงมีสิทธิ์การใช้งานอัปสตรีมอยู่ การสนับสนุน H3/ClipProj ของ Apple อยู่ในช่วงทดลอง ตัวอย่างสั้นๆ ที่ประสบความสำเร็จไม่ได้รองรับทุกความละเอียดหรือทุกระยะเวลา

## ลงชื่อเข้าใช้และบัญชี

บน Mac ที่ใช้บริการนี้ ให้เปิด `http://127.0.0.1:1235/setup` เพื่อสร้างผู้ดูแลระบบคนแรก จากนั้นลงชื่อเข้าใช้จากอุปกรณ์อื่นๆ ผู้ดูแลระบบสามารถสร้าง ปิดการใช้งาน และลบบัญชีและรีเซ็ตรหัสผ่านได้ ดู [เอกสารประกอบบัญชี](accounts.md) ([中文](../../accounts.md)) ไม่มีรหัสผ่านเริ่มต้น ไฟล์บัญชีจะยังคงอยู่ในไดเร็กทอรีข้อมูล runtime และจะต้องไม่ถูกอัปโหลด งานยังคงเป็นข้อมูลสตูดิโอที่แชร์
