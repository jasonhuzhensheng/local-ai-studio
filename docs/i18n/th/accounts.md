> เอกสารเหล่านี้เป็นการแปลข้อความโครงการสาธารณะด้วยคอมพิวเตอร์และยังไม่ได้รับการตรวจสอบโดยเจ้าของภาษาทั้งหมด ปรึกษาแหล่งข้อมูลภาษาอังกฤษหรือจีนสำหรับความคลุมเครือทางเทคนิค ไม่มีข้อมูลส่วนตัวของผู้ใช้รวมอยู่ด้วย

# บัญชีเว็บไซต์

## การใช้งาน

บน Mac ที่ใช้บริการนี้ ให้เปิด `http://127.0.0.1:1235/setup` เพื่อสร้างผู้ดูแลระบบคนแรก ชื่อผู้ใช้ประกอบด้วยตัวอักษร 3–32 ตัวเลข ขีดล่าง หรือขีดกลาง และถูกทำให้เป็นมาตรฐานให้เป็นตัวพิมพ์เล็ก รหัสผ่านประกอบด้วยอักขระ 12–128 ไม่มีข้อมูลรับรองเริ่มต้น อุปกรณ์ระยะไกลไม่สามารถอ้างสิทธิ์บัญชีผู้ดูแลระบบเริ่มต้นได้

หลังจากตั้งค่า อุปกรณ์ที่ไม่ได้รับการรับรองความถูกต้องจะเห็นหน้าลงชื่อเข้าใช้ เปิด **บัญชี / ออกจากระบบ** (`/account`) เพื่อเปลี่ยนรหัสผ่านหรือออกจากระบบ ผู้ดูแลระบบสามารถสร้าง users/administrators รีเซ็ตรหัสผ่าน บัญชี disable/enable เปลี่ยนบทบาท และลบบัญชีได้ การลบและการอนุญาตการเปลี่ยนแปลงต้องได้รับการยืนยัน เซิร์ฟเวอร์ป้องกันการลบ ปิดการใช้งาน หรือลดระดับผู้ดูแลระบบที่เปิดใช้งานครั้งล่าสุด การลบบัญชีจะไม่ลบงานที่แชร์

ใช้เมนูภาษาที่มุมขวาบนเพื่อเลือกภาษาของ 33 เบราว์เซอร์จะจดจำการเลือกของคุณ ชุดภาษามีให้บริการในพื้นที่ การเปลี่ยนภาษาไม่ได้ส่งเนื้อหาไปยังบริการแปลออนไลน์ ข้อความแจ้งของผู้ใช้ การสนทนา และเนื้อหาที่บันทึกไว้จะคงเป็นภาษาต้นฉบับ

นี่คือสตูดิโอที่ใช้ร่วมกัน ผู้ใช้ที่ลงชื่อเข้าใช้จะแชร์การเข้าถึงรูปภาพ วิดีโอ และงานแชทฝั่งเซิร์ฟเวอร์ ประวัติการแชทของเบราว์เซอร์ยังคงอยู่ใน localStorage ไม่มีการแยกผู้เช่าหลายราย การจัดเก็บงานต่อผู้ใช้ หรือการเรียกเก็บเงิน ข้อจำกัดวิดีโอเฉพาะในเครื่องที่มีอยู่ยังคงอยู่

## การจัดเก็บและการป้องกัน

- `src/studio_auth.mjs` ทำงานก่อนเส้นทางธุรกิจ รวมถึง API และไฟล์ image/reference/video หน้าที่ไม่ได้รับอนุญาตเปลี่ยนเส้นทางด้วย 303; API และสื่อส่งคืน 401 ทรัพย์สินของบัญชี ทรัพย์สินทางภาษา และสถานะ setup/sign-in ที่ไม่เป็นความลับนั้นเป็นสาธารณะ
- ไฟล์บัญชี: `LOCAL_IMAGE_DATA_DIR/auth/users.json`, `app/.local/auth/users.json` เริ่มต้น; การปรับใช้เฉพาะใช้ `runtime/auth/users.json` โหมดไดเรกทอรี: 0700; โหมดไฟล์: 0600 รหัสผ่านใช้ scrypt N32768/r8/p1 เกลือแบบสุ่ม และการเปรียบเทียบแฮชตามเวลาคงที่ การเขียนเป็นแบบอะตอมมิกและการเปลี่ยนแปลงบัญชีเป็นอนุกรม ฐานข้อมูลที่มีอยู่เสียหายจะป้องกันการเริ่มต้นระบบแทนที่จะเปิดการลงทะเบียนอีกครั้ง
- เซสชันใช้ไบต์สุ่ม 32 เซิร์ฟเวอร์จะเก็บเฉพาะข้อมูลสรุปเท่านั้น คุกกี้คือ HttpOnly, SameSite=Strict ใช้ได้สำหรับชั่วโมง 12 การรีสตาร์ทจำเป็นต้องลงชื่อเข้าใช้อีกครั้ง การเปลี่ยนแปลง Password/role รีเซ็ต การปิดใช้งาน และการลบจะเพิกถอนเซสชันที่ได้รับผลกระทบ การออกจากระบบจะไม่ลบหรือเรียกใช้งานที่เริ่มไปแล้วอีกครั้ง
- การเขียนต้องใช้ Origin และ JSON ที่มีต้นกำเนิดเดียวกัน X-Forwarded-For ไม่น่าเชื่อถือ IP ต้นทางแต่ละรายการได้รับความพยายามสูงสุด 15 sign-in/setup/self-password-change ต่อ 15 นาที ขีดจำกัด: การสร้างรหัสผ่าน 4 ที่เกิดขึ้นพร้อมกันและบัญชี 100 การรีสตาร์ทจะล้างขีดจำกัดความพยายาม
- การใช้งานที่มีอยู่ใช้ HTTP ผ่าน Tailscale ส่วนตัว Tailscale เข้ารหัสการขนส่งระหว่างอุปกรณ์ LAN HTTP ธรรมดานั้นไม่ได้เป็นเช่นนั้น แพ็คเกจนี้ไม่ได้กำหนดค่าการเข้าถึงสาธารณะและ TLS คุกกี้ Secure ได้รับการตั้งค่าสำหรับคำขอ TLS ดั้งเดิมเท่านั้น อย่าเปิดเผยโดยตรงผ่าน HTTP สาธารณะ
- ห้ามอัปโหลดฐานข้อมูลการรับรองความถูกต้อง เซสชัน หรือรหัสผ่าน เริ่มต้นบัญชีใหม่เมื่อทำการโยกย้าย การอนุญาตไฟล์ stdio MCP, LM Studio ในเครื่อง และ OS เป็นการตรวจสอบสิทธิ์ภายนอกเว็บไซต์

## การตรวจสอบ

เรียกใช้ `node tests/studio_auth.mjs` ด้วยฐานข้อมูลบัญชีชั่วคราว และไม่มี models จริง โดยครอบคลุมการบล็อก API/media ที่ไม่ได้รับการรับรองความถูกต้อง ข้อจำกัดต้นกำเนิดการตั้งค่าเริ่มต้น บทบาท โหมดรหัสผ่าน hashing/file การป้องกันผู้ดูแลระบบคนสุดท้าย การเพิกถอนเซสชัน การคงอยู่ การปฏิเสธไฟล์ที่เสียหาย และการจำกัดอัตรา

การทดสอบ local_chat, chat_พื้นหลัง, image_studio และ video_web ลงชื่อเข้าใช้ด้วยผู้ดูแลระบบการทดสอบแบบแยกส่วน ไม่มีการบายพาสการรับรองความถูกต้องการผลิต ผู้ใช้ป้อนรหัสผ่านจริงและจะต้องไม่ถูกบันทึกไว้ในการทดสอบหรือเอกสารประกอบ
