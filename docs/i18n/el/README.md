# MacBook Pro Studio

Ένα τοπικό στούντιο εικόνας, συνομιλίας και πειραματικού βίντεο για Apple Silicon Mac.

## Γλώσσα διεπαφής

Χρησιμοποιήστε το μενού γλώσσας επάνω δεξιά για να επιλέξετε από τις γλώσσες 33. Το πρόγραμμα περιήγησης θυμάται την επιλογή σας. Τα πακέτα γλωσσών σερβίρονται τοπικά. Η αλλαγή γλώσσας δεν στέλνει περιεχόμενο σε μια διαδικτυακή υπηρεσία μετάφρασης. Οι προτροπές χρήστη, οι συνομιλίες και το αποθηκευμένο περιεχόμενο διατηρούν την αρχική τους γλώσσα.

## Προεπισκοπήσεις διεπαφής

Αυτές οι προεπισκοπήσεις χρησιμοποιούν τα δημοσιευμένα στυλ σελίδας. Όλα τα μηνύματα προτροπής, τα αναγνωριστικά εργασιών, οι χρονικές σημάνσεις, οι εικόνες και οι συνομιλίες είναι φανταστικό περιεχόμενο επίδειξης που δημιουργήθηκε για αυτό το README. Δεν περιέχουν πραγματικούς λογαριασμούς, εικόνες χρηστών ή αρχεία συνομιλίας. Οι εικόνες σχεδιάζονται μέσω προγραμματισμού, όχι δείκτες αναφοράς μοντέλων ή ισχυρισμοί ποιότητας.

## Ρύθμιση νέου Mac

1. Κλωνοποιήστε αυτό το αποθετήριο.
2. Διαβάστε τον [οδηγό ανάπτυξης](README-FIRST.txt) ([中文](../../../README-先读我.txt)).
3. Δώστε το [installation prompt](INSTALL-PROMPT.txt) ([中文](../../../INSTALL-PROMPT.txt)) σε έναν βοηθό κωδικοποίησης στο Mac-στόχο για να εγκαταστήσει εξαρτήσεις και να κατεβάσει το models κατάλληλο για αυτό το υλικό.

Σελίδες: `/edit` για εικόνες, `/chat` για συνομιλία, `/video` για βίντεο. Η προεπιλεγμένη θύρα Ιστού είναι `1235`.

Αυτό το αποθετήριο είναι ένα ελεγμένο αντίγραφο έκδοσης και μετεγκατάστασης. Μπορεί να υστερεί σε σχέση με την τοπική ανάπτυξη ή παραγωγή. Εξαιρούνται τα βάρη μοντέλων, τα εικονικά περιβάλλοντα, οι εργασίες χρήστη, οι εγγραφές συνομιλιών, οι εικόνες αναφοράς και η διαμόρφωση λογαριασμού. Δεν έχει επικυρωθεί πλήρης εγκατάσταση σε νέο μηχάνημα. Αυτή δεν είναι μια εφαρμογή με ένα κλικ.

## Περιεχόμενα αποθήκης

- `src/`: frontend, backend, δηλώσεις μοντέλων, εργαλεία εγκατάστασης και επικύρωσης.
- `tests/`: δοκιμές. Ορισμένα απαιτούν εγκατεστημένο models ή εκτελούμενες υπηρεσίες.
- `requirements/`: καρφιτσωμένες εξαρτήσεις.
- `vendor/`: εγγενής πηγή κινητήρα, με διατηρημένες άδειες ανάντη.
- `patches/`: καρφιτσωμένες εκδόσεις και προσαρμογές της Apple.

Τα μοντέλα και η πηγή τρίτων διατηρούν τις άδειες χρήσης τους. H3/ClipProj Η υποστήριξη της Apple είναι πειραματική. Ένα επιτυχημένο σύντομο δείγμα δεν παρέχει υποστήριξη για κάθε ανάλυση ή διάρκεια.

## Είσοδος και λογαριασμοί

Στο Mac που εκτελεί την υπηρεσία, ανοίξτε το `http://127.0.0.1:1235/setup` για να δημιουργήσετε τον πρώτο διαχειριστή και, στη συνέχεια, συνδεθείτε από άλλες συσκευές. Οι διαχειριστές μπορούν να δημιουργήσουν, να απενεργοποιήσουν και να διαγράψουν λογαριασμούς και να επαναφέρουν τους κωδικούς πρόσβασης. Δείτε [τεκμηρίωση λογαριασμού](accounts.md) ([中文](../../accounts.md)). Δεν υπάρχει προεπιλεγμένος κωδικός πρόσβασης. Τα αρχεία λογαριασμού παραμένουν στον κατάλογο δεδομένων runtime και δεν πρέπει να μεταφορτωθούν. Οι εργασίες παραμένουν κοινόχρηστα δεδομένα στούντιο.
