Эти документы представляют собой машинный перевод текста публичного проекта и не все были проверены носителями языка. Обратитесь к английскому или китайскому источнику для устранения технической двусмысленности. Никакие личные данные пользователя не включены.

Local AI Studio: исходный пакет миграции для нового Apple Silicon Mac.

Этот рассматриваемый выпуск включает исходный код frontend/backend, тесты, манифесты загрузки моделей, закрепленные зависимости, собственный исходный код движка и экспериментальные видеопатчи Apple. Оно может отставать от местного развития или производства.
Он исключает веса, виртуальные среды, предыдущие задачи, эталонные изображения, записи чата, конфигурацию учетной записи и секреты. Это не app в один клик.

Передайте всю эту папку помощнику по программированию на целевом Mac вместе с INSTALL-PROMPT.en.txt.
Исходной машиной для проверки была M2 Max с памятью 96GB. Сначала проверьте целевую модель, память и ОС. Не используйте настройки видео вслепую повторно на компьютерах Mac с малым объемом памяти.

Содержание:
 src/ Интерфейс, серверная часть, инструменты download/validation, манифесты моделей
 tests/ Тесты; некоторые требуют установленного models/services. Не запускайте все без разбора
 requirements/viggle-pinned.txt Среда закрепленных изображений
 src/h3_requirements.lock Отдельная закрепленная видеосреда
 vendor/ Собственный исходный код без скомпилированных двоичных файлов; сохранить лицензии на добычу полезных ископаемых
 patches/ ComfyUI/ClipProj фиксирует и развертывает изменения Python
 SHA256SUMS.txt Контрольные суммы для каждого файла

Точки входа модели: image_models.json (Qwen GGUF), viggle_turbo_model.json / viggle_turbo_v021_model.json / viggle_turbo_v03_model.json (базовый model/adapters), wai_model.json, upscale_model.json и h3_apple_models.json (видео), в разделе src/. Перед загрузкой проверьте каждый манифест и его установщик.
Текстовая модель: huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF, файл Huihui-Qwen3.8-27B-abliterated-UD-Q4_K_XL.gguf. В этот пакет не входит полный прикрепленный revision/hash для этой модели. Сначала получите и запишите доверенные восходящие метаданные; не заявляйте о побайтовой эквивалентности исходной машине.

Установка новой машины не была проверена. Просмотрите пути к исходному компьютеру, псевдонимы моделей и пути к системным инструментам для целевого пользователя. Не применяйте повторно исторические исправления к уже измененному исходному коду поставщика. Успешная загрузка не является свидетельством успешного вывода или приемлемого качества.

Используйте языковое меню в правом верхнем углу, чтобы выбрать один из языков 33. Браузер запоминает ваш выбор. Языковые пакеты обслуживаются локально; при переключении языков контент не отправляется в службу онлайн-перевода. Подсказки пользователя, разговоры и сохраненный контент сохраняют исходный язык.
