# MacBook Pro Studio

Местная студия изображений, чатов и экспериментального видео для компьютеров Mac Apple Silicon.

## Язык интерфейса

Используйте языковое меню в правом верхнем углу, чтобы выбрать один из языков 33. Браузер запоминает ваш выбор. Языковые пакеты обслуживаются локально; при переключении языков контент не отправляется в службу онлайн-перевода. Подсказки пользователя, разговоры и сохраненный контент сохраняют исходный язык.

## Предварительный просмотр интерфейса

В этих предварительных просмотрах используются выпущенные стили страниц. Все подсказки, идентификаторы задач, временные метки, иллюстрации и диалоги представляют собой вымышленный демонстрационный контент, созданный для этого README. Они не содержат реальных учетных записей, изображений пользователей или записей чата. Иллюстрации нарисованы программно, а не являются эталонными моделями или заявлениями о качестве.

## Настройте новый Mac

1. Клонируйте этот репозиторий.
2. Прочтите [руководство по развертыванию ](README-FIRST.txt) ([中文](../../../README-先读我.txt)).
3. Передайте [подсказку установки ](INSTALL-PROMPT.txt) ([中文](../../../INSTALL-PROMPT.txt)) помощнику по программированию на целевом Mac, чтобы установить зависимости и загрузить models, подходящий для этого оборудования.

Страницы: `/edit` для изображений, `/chat` для чата, `/video` для видео. Веб-порт по умолчанию — `1235`.

Этот репозиторий представляет собой проверенную копию выпуска и миграции. Оно может отставать от местного развития или производства. Сюда не входят веса моделей, виртуальные среды, пользовательские задачи, записи чата, эталонные изображения и конфигурация учетной записи. Полная установка на новую машину не была проверена. Это не приложение в один клик.

## Содержимое репозитория

- `src/`: интерфейс, серверная часть, манифесты моделей, инструменты установки и проверки.
- `tests/`: тесты; для некоторых требуется установленный models или запущенные службы.
- `requirements/`: закрепленные зависимости.
- `vendor/`: собственный исходный код движка с сохранением исходных лицензий.
- `patches/`: закрепленные версии и адаптации Apple.

Модели и сторонние источники сохраняют свои исходные лицензии. H3/ClipProj Поддержка Apple является экспериментальной. Успешный короткий образец не обеспечивает поддержку каждого разрешения или продолжительности.

## Вход и аккаунты

На Mac, на котором запущена служба, откройте `http://127.0.0.1:1235/setup`, чтобы создать первого администратора, а затем войдите в систему с других устройств. Администраторы могут создавать, отключать и удалять учетные записи и сбрасывать пароли. См. [документацию по аккаунту ](accounts.md) ([中文](../../accounts.md)). Пароля по умолчанию нет. Файлы учетной записи остаются в каталоге данных runtime и не подлежат загрузке. Задачи остаются общими данными студии.
