Tyto dokumenty jsou strojovým překladem textu veřejného projektu a ne všechny byly zkontrolovány rodilými mluvčími. Technické nejasnosti naleznete v anglickém nebo čínském zdroji. Nejsou zahrnuta žádná soukromá uživatelská data.

Nasaďte zdrojový balíček Local AI Studio na tento nový počítač. Migrujte stávající zdroj; nepřestavujte podobný web od začátku.

1. Přečtěte si README-FIRST.en.txt a zdroj. Zkontrolujte OS, architekturu, paměť, volný disk, GPU a nainstalované nástroje. Nahlásit kompatibilitu. Apple Silicon je ověřená platforma; identifikovat adaptační práce pro jiné platformy namísto nároku na přímou podporu.
2. Použijte ~/Library/Application Support/LocalImageStudio: app pro zdroj, runtime pro environments/engines/tasks, models pro závaží. Nastavte app/.local -> ../runtime a runtime/image-models -> ../models. Vyhněte se iCloudu Desktop/Documents. Nepoužívejte znovu stará uživatelská jména, IP adresy nebo identity Tailnet.
3. Nainstalujte požadované stabilní nástroje: Python 3.11, Node (zdrojový stroj použil 25), CMake, nástroje pro sestavení a LM Studio. Použijte izolovaná prostředí a nainstalujte závislosti image/video odděleně od requirements/viggle-pinned.txt a src/h3_requirements.lock. Pokud je verze nedostupná nebo nekompatibilní, místo tichého upgradu nahlaste selhání. Adaptace Apple H3/ClipProj je experimentální.
4. Nasaďte vendor/stable-diffusion.cpp a vendor/ggml-source do runtime. Zdroj již obsahuje změny; neaplikujte historické záplaty dvakrát. Použijte konfiguraci CMake: -DSD_METAL=ON -DSD_WEBP=OFF -DSD_WEBM=OFF -DSD_GGML_SOURCE_DIR=<absolute cesta ggml> -DCMAKE_BUILD_TYPE=Release. Sestavte sd-cli a další cíle požadované kódem.
5. Stáhněte si připnuté revize pomocí manifestů a instalačních programů modelu JSON pod src/. Podpora obnovení a ověření sizes/SHA256. Získejte důvěryhodné upstream hash tam, kde chybí, a zaznamenejte je; nikdy nevymýšlejte hashe. Vyberte spustitelné moduly podle kapacity memory/disk; nenahrazujte v tichosti models. Nainstalujte textový model specifikovaný souborem README do LM Studio s aliasem používaným kódem, místním portem API 1234. Nekopírujte starou konfiguraci účtu.
6. Nainstalujte video samostatně do video-experimental: ComfyUI z https://github.com/comfyanonymous/ComfyUI a ClipProj ze https://github.com/nicolab28/ComfyUI-ClipProj. Připněte odevzdání zaznamenané v patches/ a použijte každý deployed.patch jednou. Stáhněte a ověřte aktiva h3_apple_models.json. Zachovejte ochranu paměti. Neaplikujte také src/h3_apple_*.patch. Zkontrolujte aktuální kód podporované kombinace resolution/frame/audio; nerozšiřujte neověřené možnosti.
7. Auditujte pevně zakódované /Users/ cesty, proměnné prostředí, adresáře modelů a spustitelné soubory pro cílový počítač. Zachovat /edit, /chat, /video, úlohu IDs/queues/progress, potvrzení smazání, úlohy chatu na pozadí a reference. Neimportujte staré obrázky chats/tasks/reference. Zachovejte výběr 中文 / angličtina a jazykové preference.
8. Spusťte node app/src/image_gallery.mjs ve smyčce s prostředím definovaným zdrojem. Ověřte HTTP a připravenost modelu. Vyhněte se konfliktům na portech 1235 (web), 1234 (textové API), 8191 (video backend). Konfigurujte LAN/private Tailscale pouze na vyžádání; nepovolte veřejné Funnel. Přečtěte si adresu nového zařízení namísto opětovného použití staré adresy.
9. Proveďte příslušné izolované testy. S nově napsanými necitlivými výzvami ověřte kompletní odpovědi chatu, stop/reconnect po obnovení, skutečný obrazový výstup s vizuální kontrolou a přehratelné krátké video. Záznam time/dimensions/memory. HTTP 200 nebo samotná existence souboru není akceptována.
10. Nakonfigurujte spuštění po přihlášení místního uživatele, zobrazované jméno Local AI Studio. Pokud je požadována operace před přihlášením, zkontrolujte nejprve omezení OS/FileVault. Přihlášení LaunchAgent se nespustí bez přihlášení.
11. Uložte místní pokyny k nasazení, příkazy start/stop, verze paths/model/dependency a výsledky ověření. Nečtěte nesouvisející soukromé soubory. Nechte uživatele zadat hesla správce nebo přihlašovací údaje k účtu; pokračovat v dalších autorizovaných instalačních pracích. Uveďte zbývající blokátory a nikdy neprohlašujte, že neprovedené kontroly prošly.
12. Ověřování webových stránek je ve výchozím nastavení povoleno. Požádejte uživatele, aby vytvořil prvního správce v místním /setup a poté otestoval ověřená obchodní rozhraní API. Očekává se neověřený /api/models vracející 401. Nezakazujte ověřování ani nekopírujte starou databázi účtů. Viz docs/accounts.en.md.
