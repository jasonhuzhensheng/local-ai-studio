Local AI Studio: 新しい Apple Silicon Mac の移行ソース パッケージ

このレビュー済みリリースには、frontend/backend ソース、テスト、モデル ダウンロード マニフェスト、固定された依存関係、ネイティブ エンジン ソース、実験的な Apple ビデオ パッチが含まれています。現地での開発や生産より遅れる可能性があります。
これには、重み、仮想環境、以前のタスク、参照画像、チャット記録、アカウント構成、およびシークレットは含まれません。ワンクリックのappではありません。

このフォルダー全体を、INSTALL-PROMPT.en.txt とともにターゲット Mac 上のコーディング アシスタントに渡します。
元の検証マシンは、96GB メモリを搭載した M2 Max でした。まずは対象機種、メモリ、OSをご確認ください。メモリの少ない Mac でビデオ設定をむやみに再利用しないでください。

内容:
 src/ フロントエンド、バックエンド、download/validation ツール、モデル マニフェスト
 tests/ テスト;一部は models/services. のインストールが必要です。すべてを無差別に実行しないでください。
 requirements/viggle-pinned.txt ピン留めされた画像環境
 src/h3_requirements.lock 個別の固定ビデオ環境
 vendor/ コンパイルされたバイナリを含まないネイティブ ソース。アップストリームライセンスを保持する
 patches/ ComfyUI/ClipProj のコミットとデプロイされた Python の変更
 SHA256SUMS.txt ファイルごとのチェックサム

モデル エントリ ポイント: image_models.json (Qwen GGUF)、viggle_turbo_model.json / viggle_turbo_v021_model.json / viggle_turbo_v03_model.json (ベース model/adapters)、wai_model.json、upscale_model.json および h3_apple_models.json (ビデオ)、src/. の下 ダウンロードする前に、各マニフェストとそのインストーラーを確認してください。
テキスト モデル: huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF、ファイル Huihui-Qwen3.8-27B-abliterated-UD-Q4_K_XL.gguf。このパッケージには、そのモデル用の完全なピン留めされた revision/hash は含まれていません。まず、信頼できるアップストリームのメタデータを取得して記録します。元のマシンとバイトごとに同等であると主張しないでください。

新しいマシンのインストールは検証されていません。対象ユーザーの元のマシンのパス、モデルのエイリアス、システム ツールのパスを確認します。すでに変更されたベンダー ソースに過去のパッチを再適用しないでください。ダウンロードの成功は、推論の成功や許容可能な品質の証拠にはなりません。
