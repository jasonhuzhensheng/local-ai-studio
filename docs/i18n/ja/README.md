# MacBook Pro Studio

Apple Silicon Mac 用のローカル画像、チャット、実験的なビデオ スタジオ。

## インターフェース言語

右上の言語メニューを使用して、33 言語から選択します。ブラウザは選択内容を記憶します。言語パックはローカルで提供されます。言語を切り替えても、コンテンツはオンライン翻訳サービスに送信されません。ユーザープロンプト、会話、保存されたコンテンツは元の言語を維持します。

## インターフェースのプレビュー

これらのプレビューでは、リリースされたページ スタイルが使用されます。すべてのプロンプト、タスク ID、タイムスタンプ、イラスト、会話は、この README 用に作成された架空のデモ コンテンツです。これらには、実際のアカウント、ユーザー画像、チャット記録は含まれません。イラストはプログラムによって描画されたものであり、モデルのベンチマークや品質の主張ではありません。

## 新しい Mac をセットアップする

1。このリポジトリのクローンを作成します。
2。 [展開ガイド](README-FIRST.txt) ([中文](../../../README-先读我.txt))] をお読みください。
3。 [インストール プロンプト](INSTALL-PROMPT.txt) ([中文](../../../INSTALL-PROMPT.txt)]) をターゲット Mac のコーディング アシスタントに渡して、依存関係をインストールし、そのハードウェアに適した models をダウンロードします。

ページ: 画像の場合は `/edit`、チャットの場合は `/chat`、ビデオの場合は `/video`。デフォルトの Web ポートは `1235` です。

このリポジトリは、レビュー済みのリリースおよび移行コピーです。現地での開発や生産より遅れる可能性があります。モデルの重み、仮想環境、ユーザー タスク、チャット記録、参照画像、アカウント構成は含まれません。新しいマシンへの完全なインストールは検証されていません。これはワンクリックアプリケーションではありません。

## リポジトリの内容

- `src/`: フロントエンド、バックエンド、モデル マニフェスト、インストールおよび検証ツール。
- `tests/`: テスト。インストールされた models または実行中のサービスが必要なものもあります。
- `requirements/`: 固定された依存関係。
- `vendor/`: ネイティブ エンジン ソース。アップストリーム ライセンスは保持されます。
- `patches/`: 固定バージョンと Apple 適応。

モデルとサードパーティ ソースはアップストリーム ライセンスを保持します。 H3/ClipProj Apple サポートは実験的なものです。短いサンプルが成功しても、すべての解像度や期間のサポートが確立されるわけではありません。

## サインインとアカウント

サービスを実行している Mac で、`http://127.0.0.1:1235/setup` を開いて最初の管理者を作成し、他のデバイスからサインインします。管理者は、アカウントを作成、無効化、削除し、パスワードをリセットできます。 [アカウントドキュメント](accounts.md) ([中文](../../accounts.md))]を参照してください。デフォルトのパスワードはありません。アカウント ファイルは runtime データ ディレクトリに残るため、アップロードしないでください。タスクは共有されたスタジオ データのままになります。
