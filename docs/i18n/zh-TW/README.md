## 設定新 Mac

1。克隆這個儲存庫。
2。閱讀[部署指南](README-FIRST.txt) ([中文](../../../README-先读我.txt))]。
3。將安裝提示](INSTALL-PROMPT.txt) ([中文](../../../INSTALL-PROMPT.txt)) 傳送給目標Mac 上的編碼助手，以安裝依賴項並下載適合該硬體的models。

頁面：`/edit` 用於圖像，`/chat` 用於聊天，`/video` 用於視訊。預設 Web 連接埠是 `1235`。

該存儲庫是經過審查的版本和遷移副本。它可能落後於當地的開發或生產。它不包括模型權重、虛擬環境、使用者任務、聊天記錄、參考影像和帳戶配置。新機器上的完整安裝尚未經過驗證。這不是一鍵式應用程式。

## 儲存庫內容

- `src/`：前端、後端、模型清單、安裝和驗證工具。
- `tests/`：測試；有些需要安裝 models 或執行服務。
- `requirements/`：固定依賴項。
- `vendor/`：本機引擎來源，保留上游授權。
- `patches/`：固定版本和 Apple 改編。

模型和第三方來源保留其上游許可證。 H3/ClipProj Apple 支援是實驗性的。成功的簡短樣本並不能為每個解析度或持續時間建立支援。

## 登入和帳戶

在執行服務的 Mac 上，開啟 `http://127.0.0.1:1235/setup` 建立第一個管理員，然後從其他裝置登入。管理員可以建立、停用和刪除帳戶以及重設密碼。請參閱[帳戶文檔](accounts.md) ([中文](../../accounts.md))]。沒有預設密碼。帳戶檔案保存在runtime資料目錄中，不得上傳。任務仍然是共享的工作室數據。
