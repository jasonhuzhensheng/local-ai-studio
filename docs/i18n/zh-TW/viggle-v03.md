# Viggle v0.3 安裝與模式

官方來源：https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo

固定版本、大小和雜湊值：`src/viggle_turbo_v03_model.json`。安裝人員：`src/install_viggle_turbo_v03.py`。使用單獨的 `models/viggle-qwen-turbo-v03` 目錄，同時分享已安裝的基礎模型和現有的 Python 環境。它不會升級依賴項或覆蓋 v0.1/v0.2.1.

圖像模型選單提供：

- **Viggle v0.3 · 6 步驟，更清晰的圖像**：官方 6-node sigma 時間表，CFG1。
- **Viggle v0.3 · 9 步驟，增強細節**：七個 Turbo 步驟，然後停用 LoRA，將下一個快取的 KV 傳遞切換到擷取，並使用基礎模型進行最後兩個步驟。 LoRA 和轉發行為隨後恢復。僅將常規步數設為九是不等效的。

v0.3 最多支持三个引用，无否定提示，选择时默认为 1024px 方形。保留之前的 v0.2.1 默认和 iPhone 尺寸；原始模型仍然支持十个参考。原生大尺寸、VAE 平铺和现有 8K 后处理仍然可选，但并非每种组合都经过测试。

LoRA 沒有融合到 BF16 權重中；強度為1。調度器 `shift_terminal` 必須是 null。 v0.3 顆粒感可以少一些，但稍微軟一些；不保證在任何情況下都優於舊版本。官方九步計時比率並非當地基準。

## 驗證

`tests/viggle_model.mjs` 使用隔離的稀疏模型夾具來驗證步數、參考限制、大尺寸路由和就緒標記。 `tests/viggle_schedule.py` 在第七步（1 KV 重新提取和恢復）後驗證禁用 LoRA。

六步驟 512×512、種子 42 藍杯樣品在 52.98 中完成，包括 process/model 加載。檢查尺寸和實際影像。當新的文字連結觸發資源保護時，第一個九步驟嘗試停止；這不是推理錯誤。

九步驟重試在 65.42 時間內完成，時間為 512×512，種子為 42。它在第七步後切換到基本模型，完成九步並產生正確的尺寸。目視檢查未發現 green/magenta 噪音。每種模式一個樣本並不是穩定的效能基準。這些運行未驗證多個參考、大圖像和 8K 後處理。
