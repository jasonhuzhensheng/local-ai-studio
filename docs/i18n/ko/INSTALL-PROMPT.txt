이 문서는 공개 프로젝트 텍스트의 기계 번역이며 원어민이 모두 검토하지는 않았습니다. 기술적 모호성에 대해서는 영어 또는 중국어 소스를 참조하세요. 개인 사용자 데이터는 포함되지 않습니다.

이 새로운 머신에 Local AI Studio 소스 패키지를 배포합니다. 기존 소스를 마이그레이션합니다. 유사한 웹사이트를 처음부터 다시 구축하지 마세요.

1. README-FIRST.en.txt와 소스를 읽어보세요. OS, 아키텍처, 메모리, 여유 디스크, GPU 및 설치된 도구를 검사합니다. 보고서 호환성. Apple Silicon는 검증된 플랫폼입니다. 직접적인 지원을 주장하는 대신 다른 플랫폼에 대한 적응 작업을 식별합니다.
2. 소스에는 ~/Library/Application Support/LocalImageStudio: app, environments/engines/tasks에는 runtime, 가중치에는 models를 사용합니다. app/.local -> ../runtime 및 runtime/image-models -> ../models. 설정 iCloud Desktop/Documents. 방지 이전 사용자 이름, IP 또는 Tailnet ID를 재사용하지 마십시오.
3. 필요한 안정적인 도구를 설치합니다: Python 3.11, Node(소스 머신에서는 25를 사용함), CMake, 빌드 도구 및 LM Studio. 격리된 환경을 사용하고 requirements/viggle-pinned.txt 및 src/h3_requirements.lock.와 별도로 image/video 종속성을 설치합니다. 버전을 사용할 수 없거나 호환되지 않는 경우 자동으로 업그레이드하는 대신 실패를 보고하세요. H3/ClipProj Apple 적응은 실험적입니다.
4. vendor/stable-diffusion.cpp 및 vendor/ggml-source를 runtime에 배포합니다. 소스에 이미 변경 사항이 포함되어 있습니다. 역사적인 패치를 두 번 적용하지 마십시오. CMake 구성을 사용하십시오. -DSD_METAL=ON -DSD_WEBP=OFF -DSD_WEBM=OFF -DSD_GGML_SOURCE_DIR=<absolute ggml path> -DCMAKE_BUILD_TYPE=Release. sd-cli 및 코드에 필요한 기타 대상을 빌드합니다.
5. JSON 모델 매니페스트와 src/. 아래의 설치 프로그램을 사용하여 고정된 개정판을 다운로드합니다. sizes/SHA256. 지원 재개 및 확인 누락된 곳에서 신뢰할 수 있는 업스트림 해시를 확보하고 기록합니다. 해시를 발명하지 마십시오. memory/disk 용량에 따라 실행 가능한 모듈을 선택하십시오. 조용히 models를 대체하지 마십시오. 코드에서 사용하는 별칭인 로컬 API 포트 1234를 사용하여 LM Studio에 README 지정 텍스트 모델을 설치합니다. 이전 계정 구성을 복사하지 마십시오.
6. video-experimental에 비디오를 별도로 설치합니다: https://github.com/comfyanonymous/ComfyUI의 ComfyUI 및 https://github.com/nicolab28/ComfyUI-ClipProj.의 ClipProj patches/에 기록된 커밋을 고정하고 각 deployed.patch를 한 번 적용합니다. h3_apple_models.json 자산을 다운로드하고 확인하세요. 메모리 보호를 유지합니다. src/h3_apple_*.patch도 적용하지 마십시오. 현재 코드에서 지원되는 resolution/frame/audio 조합을 확인하세요. 검증되지 않은 기능을 확장하지 마십시오.
7. 대상 시스템에 대해 하드코딩된 /Users/ 경로, 환경 변수, 모델 디렉터리 및 실행 파일을 감사합니다. /edit, /chat, /video, 작업 IDs/queues/progress, 삭제 확인, 백그라운드 채팅 작업 및 참조를 유지합니다. 오래된 chats/tasks/reference 이미지를 가져오지 마세요.中文/English 선택기와 언어 기본 설정을 유지합니다.
8. 소스 정의 환경을 사용하여 루프백에서 node app/src/image_gallery.mjs를 시작합니다. HTTP 및 모델 준비 상태를 확인합니다. 포트 1235(웹), 1234(텍스트 API), 8191(비디오 백엔드)에서 충돌을 피하세요. 요청된 경우에만 LAN/private Tailscale를 구성하십시오. 공개 Funnel를 활성화하지 마십시오. 이전 주소를 재사용하는 대신 새 장치의 주소를 읽으십시오.
9. 관련 격리된 테스트를 실행합니다. 새로 작성된 민감하지 않은 프롬프트를 통해 전체 채팅 응답, 새로 고침 후 stop/reconnect, 육안 검사를 통한 실제 이미지 출력 및 재생 가능한 짧은 비디오를 확인합니다. 레코드 time/dimensions/memory. HTTP 200 또는 파일 존재만으로는 허용되지 않습니다.
10. 로컬 사용자 로그인 후 시작을 구성하고 표시 이름은 Local AI Studio입니다. 사전 로그인 작업이 요청되면 먼저 OS/FileVault 제약 조건을 확인하세요. 로그인 LaunchAgent는 로그인 없이는 시작되지 않습니다.
11. 로컬 배포 지침, start/stop 명령, paths/model/dependency 버전 및 검증 결과를 저장합니다. 관련되지 않은 개인 파일을 읽지 마십시오. 사용자가 관리자 비밀번호나 계정 로그인을 입력하도록 허용합니다. 다른 승인된 설치 작업을 계속하십시오. 남아있는 방해 요소를 확인하고 수행되지 않은 검사가 통과되었다고 주장하지 마십시오.
12. 웹사이트 인증은 기본적으로 활성화되어 있습니다. 사용자가 로컬 /setup에서 첫 번째 관리자를 생성한 다음 인증된 비즈니스 API를 테스트하도록 합니다. 401를 반환하는 인증되지 않은 /api/models가 예상됩니다. 인증을 비활성화하거나 이전 계정 데이터베이스를 복사하지 마십시오. docs/accounts.en.md. 참조
