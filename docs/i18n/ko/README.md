# MacBook Pro Studio

Apple Silicon Mac용 로컬 이미지, 채팅 및 실험적 비디오 스튜디오입니다.

## 인터페이스 언어

오른쪽 상단의 언어 메뉴를 사용하여 33 언어 중에서 선택하세요. 브라우저는 귀하의 선택을 기억합니다. 언어 팩은 로컬로 제공됩니다. 언어 전환은 콘텐츠를 온라인 번역 서비스로 보내지 않습니다. 사용자 메시지, 대화 및 저장된 콘텐츠는 원래 언어를 유지합니다.

## 인터페이스 미리보기

이러한 미리보기는 출시된 페이지 스타일을 사용합니다. 모든 프롬프트, 작업 ID, 타임스탬프, 그림 및 대화는 이 README용으로 작성된 가상의 데모 콘텐츠입니다. 여기에는 실제 계정, 사용자 이미지 또는 채팅 기록이 포함되어 있지 않습니다. 그림은 모델 벤치마크나 품질 주장이 아닌 프로그래밍 방식으로 그려졌습니다.

## 새로운 Mac 설정하기

1. 이 저장소를 복제하세요.
2. [배포 가이드](README-FIRST.txt)([中文](../../../README-先读我.txt))]를 읽어보세요.
3. 종속성을 설치하고 해당 하드웨어에 적합한 models를 다운로드하려면 대상 Mac의 코딩 보조자에게 [설치 프롬프트](INSTALL-PROMPT.txt)([中文](../../../INSTALL-PROMPT.txt)))를 제공합니다.

페이지: 이미지용 `/edit`, 채팅용 `/chat`, 비디오용 `/video`. 기본 웹 포트는 `1235`입니다.

이 저장소는 검토된 릴리스 및 마이그레이션 사본입니다. 현지 개발이나 생산보다 뒤처질 수 있습니다. 모델 가중치, 가상 환경, 사용자 작업, 채팅 기록, 참조 이미지 및 계정 구성은 제외됩니다. 새로운 시스템에 대한 전체 설치가 검증되지 않았습니다. 이것은 원클릭 애플리케이션이 아닙니다.

## 저장소 내용

- `src/`: 프런트엔드, 백엔드, 모델 매니페스트, 설치 및 검증 도구.
- `tests/`: 테스트; 일부는 models를 설치하거나 서비스를 실행해야 합니다.
- `requirements/`: 고정된 종속성.
- `vendor/`: 업스트림 라이선스가 유지되는 기본 엔진 소스입니다.
- `patches/`: 고정 버전 및 Apple 적응.

모델 및 타사 소스는 업스트림 라이선스를 유지합니다. H3/ClipProj Apple 지원은 실험적입니다. 성공적인 짧은 샘플이 모든 해결 방법이나 기간에 대한 지원을 설정하는 것은 아닙니다.

## 로그인 및 계정

서비스를 실행하는 Mac에서 `http://127.0.0.1:1235/setup`를 열어 첫 번째 관리자를 만든 다음 다른 장치에서 로그인합니다. 관리자는 계정을 생성, 비활성화, 삭제하고 비밀번호를 재설정할 수 있습니다. [계정 문서](accounts.md)([中文](../../accounts.md))]를 참조하세요. 기본 비밀번호는 없습니다. 계정 파일은 runtime 데이터 디렉터리에 있으므로 업로드하면 안 됩니다. 작업은 공유 스튜디오 데이터로 유지됩니다.
