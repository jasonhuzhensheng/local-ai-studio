> 이 문서는 공개 프로젝트 텍스트의 기계 번역이며 원어민이 모두 검토하지는 않았습니다. 기술적 모호성에 대해서는 영어 또는 중국어 소스를 참조하세요. 개인 사용자 데이터는 포함되지 않습니다.

# 웹사이트 계정

## 사용법

서비스를 실행하는 Mac에서 `http://127.0.0.1:1235/setup`를 열어 첫 번째 관리자를 만듭니다. 사용자 이름은 3–32 문자, 숫자, 밑줄 또는 하이픈을 포함하며 소문자로 정규화됩니다. 비밀번호에는 12–128 문자가 포함됩니다. 기본 자격 증명이 없습니다. 원격 장치는 초기 관리자 계정을 요구할 수 없습니다.

설정 후 인증되지 않은 장치에는 로그인 페이지가 표시됩니다. **계정 / 로그아웃**(`/account`)을 열어 비밀번호를 변경하거나 로그아웃하세요. 관리자는 users/administrators를 생성하고, 비밀번호를 재설정하고, disable/enable 계정을 설정하고, 역할을 변경하고, 계정을 삭제할 수 있습니다. 삭제 및 권한 변경에는 확인이 필요합니다. 서버는 마지막으로 활성화된 관리자를 삭제, 비활성화 또는 강등하는 것을 방지합니다. 계정을 삭제해도 공유 작업은 삭제되지 않습니다.

오른쪽 상단의 언어 메뉴를 사용하여 33 언어 중에서 선택하세요. 브라우저는 귀하의 선택을 기억합니다. 언어 팩은 로컬로 제공됩니다. 언어 전환은 콘텐츠를 온라인 번역 서비스로 보내지 않습니다. 사용자 메시지, 대화 및 저장된 콘텐츠는 원래 언어를 유지합니다.

공유 스튜디오입니다. 로그인한 사용자는 이미지, 비디오 및 서버 측 채팅 작업에 대한 액세스를 공유합니다. 브라우저 채팅 기록은 localStorage에 남아 있습니다. 다중 테넌트 격리, 사용자별 작업 저장 또는 청구가 없습니다. 기존 로컬 전용 영상 제한은 그대로 유지됩니다.

## 보관 및 보호

- `src/studio_auth.mjs`는 API 및 image/reference/video 파일을 포함하여 비즈니스 경로 이전에 실행됩니다. 인증되지 않은 페이지는 303로 리디렉션됩니다. API와 미디어는 401를 반환합니다. 계정 자산, 언어 자산 및 비밀이 아닌 setup/sign-in 상태는 공개됩니다.
- 계정 파일: `LOCAL_IMAGE_DATA_DIR/auth/users.json`, 기본 `app/.local/auth/users.json`; 전용 배포에서는 `runtime/auth/users.json`를 사용합니다. 디렉토리 모드: 0700; 파일 모드: 0600. 비밀번호는 scrypt N32768/r8/p1, 무작위 솔트 및 상수 시간 해시 비교를 사용합니다. 쓰기는 원자성이며 계정 변경사항은 직렬화됩니다. 손상된 기존 데이터베이스로 인해 등록을 다시 여는 대신 시작할 수 없습니다.
- 세션은 32 임의 바이트를 사용합니다. 서버는 다이제스트만 저장합니다. 쿠키는 HttpOnly, SameSite=Strict이며 12 시간 동안 유효합니다. 다시 시작하려면 다시 로그인해야 합니다. Password/role는 영향을 받은 세션을 변경, 재설정, 비활성화 및 삭제하면 취소됩니다. 로그아웃해도 이미 시작된 작업은 삭제되거나 다시 실행되지 않습니다.
- 쓰기에는 동일한 출처의 Origin 및 JSON가 필요합니다. X-Forwarded-For는 신뢰할 수 없습니다. 각 소스 IP는 15분당 최대 15 sign-in/setup/self-password-change 시도를 얻습니다. 제한: 4 동시 비밀번호 파생 및 100 계정. 다시 시작하면 시도 제한이 지워집니다.
- 기존 배포에서는 프라이빗 Tailscale를 통한 HTTP를 사용합니다. Tailscale는 장치 간 전송을 암호화합니다. 일반 LAN HTTP 자체는 그렇지 않습니다. 공개 액세스 및 TLS는 이 패키지로 구성되지 않습니다. Secure 쿠키는 기본 TLS 요청에 대해서만 설정됩니다. 공개 HTTP를 통해 직접 노출하지 마세요.
- 인증 데이터베이스, 세션 또는 비밀번호를 업로드하지 마십시오. 마이그레이션 시 새 계정을 초기화하세요. stdio MCP, 로컬 LM Studio 및 OS 파일 권한은 웹사이트 인증 외부에 있습니다.

## 검증

실제 models 없이 임시 계정 데이터베이스를 사용하여 `node tests/studio_auth.mjs`를 실행합니다. 인증되지 않은 API/media 차단, 초기 설정 원본 제한, 역할, 비밀번호 hashing/file 모드, 최종 관리자 보호, 세션 취소, 지속성, 손상된 파일 거부 및 속도 제한을 다룹니다.

local_chat, chat_Background, image_studio 및 video_web 테스트는 격리된 테스트 관리자로 로그인합니다. 프로덕션 인증 우회가 없습니다. 실제 비밀번호는 사용자가 입력하므로 테스트나 문서에 저장하면 안 됩니다.
