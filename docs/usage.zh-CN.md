# 使用指南

[English](usage.en.md) · [简体中文](usage.zh-CN.md) · [Docs](README.md) / [目录](README.zh-CN.md)

## 登录并选择工作区

首次在本机 `/setup` 创建管理员，在 `/login` 登录。按需进入 `/edit`、`/chat`、`/video`、`/account`。已登录账号共享任务和媒体，添加用户前请阅读[账号说明](accounts.md)。

右上角可切换界面语言。文档以英文与中文为默认维护版本，应用保留原有按浏览器语言选择及33个选项；切换不会改写输入。⌘ K / Ctrl K 用于工作区导航。

## 图片

选择已安装、已就绪的模型，填写提示词；只有支持参考图的流程才添加参考图。提交前确认尺寸、比例、步数和种子。新环境先做小图，查看结果后再提高分辨率。对比结果时明确记录缓存、增强等实验设置。

⌘ Enter / Ctrl Enter 按正常校验提交支持的表单，禁用操作仍然禁用。等待队列完成，使用产品内停止/删除按钮，不要手工删除运行目录来取消任务。

## 文字和视频

文字对话前启动 LM Studio API 并加载规定模型别名。回答设置影响请求，不代表模型已安装。浏览器历史和服务端任务是不同存储；删除账号不等于删除共享任务。

视频需独立后端，只选择支持的参考图数量、帧数和分辨率。短片成功不证明长视频、高清或音频都可用；不要绕过内存保护强行运行。

## 分享项目或作品

顶部分享入口分享公开 GitHub 项目。作品分享先打开预览：图片/视频帧可导出含项目二维码与链接的PNG，文案可复制。系统分享依赖浏览器和设备支持，不支持时可下载图片并手动复制。视频帧分享卡不等于整段视频导出。

发送前检查预览和文字；生成内容不会自动公开。新版宣传页脚或模型页专用X按钮等本机新功能可能在后续代码发布中提供，不能仅凭另一台机器的截图判断本版本已包含。

## 保留工作成果

源码更新与运行数据备份分开进行。不要用旧任务快照覆盖当前数据，也不要上传账号库。任务运行中不要重启服务。常见问题见[故障排查](troubleshooting.zh-CN.md)。
