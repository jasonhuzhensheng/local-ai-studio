# 网站账号管理

[English](accounts.en.md) | **简体中文**

## 使用

首次在运行服务的 Mac 打开 http://127.0.0.1:1235/setup，创建管理员。用户名3–32位字母/数字/下划线/短横线（统一小写）；密码12–128字符。没有默认用户名或默认密码。远程设备不能抢先注册管理员。

初始化后所有设备访问原网页地址会进入登录页。顶部“账号 / 退出”进入 /account：所有用户可改自己的密码、退出；管理员可新增普通用户/管理员、重置密码、停用、启用、切换角色及删除账号。删除和权限变更有确认，服务端不允许删除/停用/降级最后一个启用管理员。删除账号不删除共享任务。

当前是共享工作室：已登录用户共用图片/视频/服务端文字任务权限；浏览器文字历史仍保存在原 localStorage，未实现多租户、账号数据隔离或按人计费。视频原有仅本机限制保留。

界面顶部可选择中文 / English，登录及初始化页同样适用；选择仅保存在浏览器，不改变用户名或权限。

## 存储与防护

- src/studio_auth.mjs 在任何业务路由前执行，包括图片/参考图/视频文件与API。未登录网页303至登录/初始化页，API及媒体401。仅账号页面、语言切换静态资源和不含秘密的初始化/登录状态公开。
- 账号文件：LOCAL_IMAGE_DATA_DIR/auth/users.json，默认 app/.local/auth/users.json；生产位于专属目录 runtime/auth/users.json。目录0700，文件0600；scrypt N32768/r8/p1、随机盐、恒时哈希比较。原子替换文件，账号修改串行。已有账号文件损坏拒绝启动，不重置成开放注册。
- 会话：32字节随机值，服务器只保存摘要；HttpOnly、SameSite=Strict、12小时有效。重启需重新登录；重置密码、改密码、角色调整、停用或删除即时撤销相关会话。已开始生成的任务不会因退出而删除或重跑。
- 写请求必须同源Origin及JSON；不信任X-Forwarded-For。每来源IP15分钟最多15次登录/初始化/自助改密尝试，KDF最多4并发，最多100账号。失败限制会在服务重启后清除。
- 生产仍使用HTTP+私有Tailscale。Tailscale设备间有传输加密，普通局域网HTTP自身不加密；本次未开公网也未配置TLS。仅原生TLS请求带Secure cookie，不能直接放到公网HTTP。
- auth数据库、会话、密码不进入GitHub；迁移新机重新初始化。std​​io MCP、本机LM Studio及操作系统本地文件权限不属于网站登录控制范围。

## 验证

node tests/studio_auth.mjs 使用临时账号库、无真实模型：未登录API/媒体封锁，初始化来源限制，角色、密码哈希/文件权限，最后管理员保护，会话撤销，持久化、损坏拒启及限速。

local_chat/chat_background/image_studio/video_web 测试以独立测试管理员登录，没有关闭生产鉴权的开关。真实新密码由用户自行输入，不保存到测试或文档。
